Drop in a .lnk file to see exactly what it points to: target path, working directory, arguments, icon, and the tracker data Windows quietly embeds, including the machine name the shortcut was created on.

Windows Shortcut files (.lnk)

How this works: this page parses the .lnk binary format directly in your browser tab with plain JavaScript. No WebAssembly, no CDN dependency, nothing uploaded — your file is never sent anywhere.

Why this matters: a .lnk file can reveal more than its target. Windows embeds a "tracker" block with the machine name and internal disk identifiers where the shortcut was created, which is sometimes used in digital forensics and incident response to trace where a file or shortcut originated.
